# Developer Portfolio — Python Automation, Telegram Bots, Web

Демонстрационное портфолио начинающего разработчика. Каждый пример имеет ограниченный и проверяемый объём, понятную инструкцию запуска и автоматические тесты.

## Проекты

### 1. CSV Report Automation

Консольная утилита на Python, которая проверяет CSV-файл с операциями, считает суммы по статусам и формирует JSON-отчёт.

- стандартная библиотека Python;
- проверка обязательных колонок и числовых значений;
- детерминированный JSON-результат;
- unit-тесты.

### 2. Telegram Lead Bot

Демонстрационный Telegram-бот для сбора заявок: имя, телефон и комментарий.

- aiogram 3;
- пошаговый сценарий;
- валидация телефона;
- хранение заявок в SQLite;
- бизнес-логика покрыта unit-тестами;
- токен передаётся только через переменную окружения.

### 3. Responsive Landing Page

Адаптивный одностраничный сайт услуги автоматизации.

- чистые HTML, CSS и JavaScript;
- мобильная версия;
- доступная навигация;
- клиентская проверка формы;
- без внешних библиотек и трекеров.

## Проверка

```bash
python -m unittest discover -s tests -v
```

## Принципы работы

- Сначала фиксируются результат, срок и критерии приёмки.
- Секреты и токены не сохраняются в репозитории.
- Работа считается готовой только после прохождения тестов.
- Развёртывание и платные сторонние сервисы согласуются отдельно.

## Статус

Это демонстрационные проекты, а не вымышленные клиентские кейсы.
