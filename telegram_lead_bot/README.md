# Telegram Lead Bot

## Запуск

```bash
python -m venv .venv
.venv/Scripts/pip install -r telegram_lead_bot/requirements.txt
set BOT_TOKEN=token-from-botfather
python telegram_lead_bot/bot.py
```

На Linux/macOS используйте `export BOT_TOKEN=...`.

Токен запрещено сохранять в коде или коммитить в Git.
