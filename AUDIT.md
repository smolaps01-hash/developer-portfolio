# Аудит портфолио

Дата: 21 октября 2026 года.

## Цель

Сделать портфолио понятным для нетехнического заказчика, подтвердить заявленные навыки и сократить путь от просмотра страницы до содержательной заявки.

## Что мешало конверсии

1. Главный призыв вёл сразу в GitHub Issues. Для заказчика без GitHub это лишняя регистрация и возможная точка отказа.
2. Первый экран начинался с технологий, а не с результата для заказчика.
3. Не было ясного списка подходящих задач, входных данных и состава передачи.
4. Проекты описывали функции, но слабее показывали цепочку «задача → решение → проверка».
5. Не было ответов на ожидаемые вопросы о цене, сроке, данных и хостинге.
6. Базовые метаданные для поисковых систем и превью ссылок были неполными.

## Что изменено

- первый экран сфокусирован на результате и содержит прямой переход к заявке;
- добавлены три понятные категории услуг с входом и выходом;
- примеры переработаны в проверяемые мини-кейсы и честно отмечены как демонстрационные;
- добавлены состав передачи, процесс, границы работ, безопасность и FAQ;
- добавлен локальный конструктор заявки без отправки данных на сервер;
- GitHub Issues оставлен дополнительным каналом для технических заказчиков;
- добавлены canonical URL, Open Graph, JSON-LD, favicon, `robots.txt` и `sitemap.xml`;
- добавлены видимые состояния клавиатурного фокуса, связанные подписи формы и живой статус копирования;
- количество автоматических проверок увеличено с 12 до 17.

## Почему не добавлены отзывы, логотипы и проценты

Подтверждённых клиентских отзывов, названий компаний и данных о коммерческих результатах пока нет. Их имитация снизила бы доверие после проверки. Вместо этого портфолио использует открытый код, тесты, CI, документацию и явные ограничения.

## Следующий сильный шаг

После первого реального заказа добавить один обезличенный кейс только с разрешения клиента: исходная проблема, согласованный объём, фрагмент результата, способ проверки и короткий подтверждённый отзыв. Это даст более сильное социальное доказательство, чем любое количество декоративных обещаний.
